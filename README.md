# 西方现代思想讲义

自由、理性、平等与现代世界的思想史 —— 一个可自学的静态课程站点。

以刘擎《西方现代思想讲义》为核心教材整理，共 **46 个页面**：

- **20 课原书精读**：按原书导论、四章与尾声的实际讲次编排，页头标注对应章节
- **8 课拓展篇**：霍布斯、洛克、卢梭、康德、黑格尔、斯密、托克维尔、马克思、密尔 —— 原书未设专章，全部明确标注为「拓展课」
- **11 个思想专题**：按问题而非人物重组（什么是现代性、理性能否解决一切、自由与平等能否兼得、异化、民族主义、孤独与意义……）
- **索引**：思想家（28 位）、概念词典（85 条）、时间轴（1517–2008，42 条）、经典书目（33 种）

每课统一八部分：问题导入、历史背景、概念解析、思想理论、思想比较、历史影响、现实联系、延伸阅读。

## 说明

- 纯静态站点，无框架、无外部依赖、无追踪脚本，直接打开 `index.html` 即可阅读。
- 引文与讲次归属以原书为准；凡原书未涉及而由本课程补充的内容，页面与索引中均单独标注，不冒充原书章节。
- 本站为个人学习用途的读书笔记，版权归原作者刘擎及相关出版方所有。
